# 👁️ Opti-Vision

**Opti-Vision** is an AI-powered platform that provides intelligent visual analysis services through three main modules:

- 🧠 **Image Classification** — Classify images into categories using deep learning (CIFAR-10 model).
- 🎯 **Object Detection** — Identify and locate multiple objects in a single image.
- 📄 **Document Analysis** — Read, analyze, and extract information from printed or handwritten documents.

---

## 🚀 Our Mission
To make computer vision accessible to everyone by providing ready-to-use AI services for businesses, researchers, and developers.

---

## 🧩 Key Features

| Service | Description |
| :--- | :--- |
| **Image Classification** | Predicts object categories in an image using CNN models. |
| **Object Detection** | Detects objects and extracts text from scenes using YOLO + EasyOCR. |
| **Document Analysis** | Extracts structured data and text from printed and handwritten documents using OCR and NLP. |

---

## 🛠️ Technologies Used

- **Backend:** FastAPI  
- **AI Models:** TensorFlow / Keras, YOLOv8, DocTR, EasyOCR  
- **Deployment:** Uvicorn  
- **Documentation:** MkDocs Material  

---

## 📋 How to Use the Services

1. Visit the Opti-Vision web interface.
2. Choose a service: **Image Classification**, **Object Detection**, or **Document Analysis**.
3. Upload your image or document.
4. View the AI-generated analysis results in real-time.
