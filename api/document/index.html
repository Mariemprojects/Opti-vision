    📄 Enhanced Document Analysis Service¶

    The Document Analysis Service is the most advanced module of the AI Vision system.
    It provides comprehensive OCR, language detection, and structured data extraction for various document types — invoices, letters, and handwritten notes.

    ⚙️ Endpoint¶

    Method Path Description
    POST /document/analyze/enhanced Processes a document image (invoice, letter, etc.), extracts text, detects document type, and extracts structured data.

    🧰 Technologies Used¶

    -FastAPI – for serving the service endpoint.

    -Pytesseract – for traditional OCR extraction.

    -HuggingFace TrOCR – for handwritten text recognition.

    -Regex – for pattern-based extraction (dates, invoice numbers).

    -LangID + LangDetect – for multilingual text support.

    -PIL / OpenCV – for image preprocessing and enhancement.

    🧠 Pipeline Overview¶

    The system uses a multi-stage processing chain to intelligently analyze document images.
    This approach ensures the use of the most suitable tool — whether standard OCR or handwriting recognition — depending on the content.

    📋 Step-by-Step Process¶

    Step Primary Role Technology / Method Used Detailed Description
    1. Input Document image reception - The user submits a scanned or photographed image of the document.
    2. Initial OCR Extract a text preview Pytesseract A quick first read is performed on the image to obtain the raw text content needed for the next step.
    3. Classification Determine the document nature Classification Algorithm The system analyzes the raw text (Step 2) to categorize the document into a specific type: Invoice, Letter, or Handwritten.
    4. Decision Choose the optimal OCR engine Conditional Logic The system selects the best tool for the document type identified in Step 3.
    5. Specialized OCR Printed vs. Handwritten recognition Pytesseract (Printed) / TrOCR (Handwritten) The document is processed by the most effective tool for its format, ensuring the highest-quality text extraction.
    6. Post-Processing Prepare for semantic analysis langid, langdetect The extracted text (Step 5) is analyzed for language detection to improve the accuracy of later entity extraction.
    7. Entity Extraction Identify and isolate useful information Regex & Heuristics Key data (dates, amounts, reference numbers, addresses) are extracted. The free text is transformed into structured fragments of information.
    8. Output Provide the final result JSON The extracted information is structured and exported in JSON format, ready for integration with other systems.

    ⚙️ Summary¶

    This pipeline architecture combines rule-based logic and deep learning, balancing speed, adaptability, and precision.
    It allows Opti-Vision to automatically detect, interpret, and structure textual information from various document formats — from printed invoices to handwritten notes.
